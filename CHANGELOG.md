# Changelog

## v0.40 — 2026-06-15

### Features
- **Connection status**: Header connection indicator and dedicated connection status settings panel
- **Emote Picker improvements**: Better usability and performance
- **Chat Browsersource**: New OBS browser source for chat with custom styling and stick-to-bottom behavior
- **Compact mode**: Condensed chat layout option
- **Reworked Settings UI**: Fully redesigned settings with restructured navigation and appearance controls
- **Chat Appearance settings**: Granular control over chat look, including alternating backgrounds for system messages
- **YouTube chat**: Improved YouTube chat integration with better connect settings
- **Scene Switcher improvements**: Better OBS scene/stream state sync, version checks for browser sources
- **Create clip with title**: Clips can now be created with a custom title
- **Chat message on sprite reroll**: Sends a chat message when a sprite is rerolled

### Fixes
- Alert audio recovery when the output device changes
- Fixed badge, emote, and image alignment in chat
- Fixed alert player "currently playing" state
- Fixed cache busting on iOS
- Removed OBS client token exposure
- Various chat browsersource stability fixes
